The problem

Evaluation sets can drift as they are edited, making comparisons difficult to reproduce. Missing coverage can also leave a declared failure mode untested.

The solution

EvalForge uses a task specification and seed to generate versioned evaluation sets. Lint and coverage gates plus diffs between versions make changes inspectable before the set is used.

Measured outcome

What was verified.

The test suite passes 13 of 13 tests. Repeating the same spec and seed produces byte-identical output. EvalForge is published at the correct repository, evalforge-suite.
