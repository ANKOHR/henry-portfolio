ProcessMiner AI

ProcessMiner AI mines CSV event logs with deterministic rules to reconstruct observed transitions, measure stage and queue time, and rank bottlenecks and automation candidates.

Problem

The problem

A business process can be present in an event log without being documented as a flow. ProcessMiner takes timestamped activity records grouped by case and turns their observed order and timing into evidence that can be inspected before proposing where automation might fit.

Design

Design

The CSV parser converts valid rows into typed events and reports malformed values with field context. The miner orders activities within each case and builds an observed process graph with transitions and duration data. Analysis derives stage medians, wait time, queue counts, and bottleneck flags. A separate target scorer applies the published rule set to the graph, returns ranked candidates, and exposes the score inputs in JSON and Markdown or HTML reports.

Engineering decisions

Engineering decisions

The implementation uses explicit thresholds and formulas rather than a learned model. Stage timing and queue evidence are kept as separate signals so a long step and a growing queue do not collapse into one unexplained score. The bundled clean control log helps distinguish the planted bottleneck fixture from data that should produce no flags. All example records are labelled synthetic.

What the tests verify

What the tests verify

Tests check deterministic fixture generation, ordered graph edges, hand-computed medians, queue-derived bottlenecks, a control log with no flags, candidate ranking and score inputs, named malformed-row errors, stable reports, and command-line flows. These assertions check the documented rules on fixture data; they do not establish findings about a real company.
