AgentGym

AgentGym runs deterministic scripted fixture agents through synthetic multi-step tasks, records tool events, and evaluates the resulting episodes with hidden rule-based graders.

Problem

The problem

A short task score can hide how an agent got there. For a task with several tool calls, partial progress, constraints, and persistent state, an evaluation needs a durable event trail and a way to reproduce the same episode. AgentGym models that evaluation loop over synthetic task fixtures.

Design

Design

Task JSON defines the public task prompt, tools, fixture world, and scoring contract. A fixture agent receives an AgentView containing task text and declared tools plus its own memory. The runner records tool calls and results as events and persists the episode and agent checkpoint after each step. The grader scores the recorded events across completion, correctness, efficiency, and constraint respect. A separate taxonomy attaches failure categories to the event IDs that triggered them.

Engineering decisions

Engineering decisions

Grading consumes observed events and artifacts rather than an agent's own claims. The exact rubric stays outside the AgentView, while the report can show partial-credit subscores and evidence. Replay re-runs the fixture agent and compares the regenerated events, score, and failure labels against the saved episode. Synthetic tasks and scripted agents make those checks reproducible without model calls.

What the tests verify

What the tests verify

The suite checks task schema and unique IDs, hand-calculated partial scores, what information is exposed to the agent, byte-identical runs, per-step checkpoint durability, and resume equivalence with an uninterrupted run. It also checks replay, event-linked failure labels for looping and permission fixtures, report evidence, and the synthetic-only notice in the CLI and HTML report.
