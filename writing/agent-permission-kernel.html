APK is a policy decision engine for in-memory fixtures. It is not an operating-system sandbox, Gmail integration, or production security boundary, and it does not access host files or accounts. tests

Agent Permission Kernel

The Agent Permission Kernel compiles capability policies, checks each synthetic operation, enforces directory scopes and spend caps, and records allow, deny, or human escalation decisions.

Problem

The problem

A broad permission such as "can use email" hides which operation is allowed, while a filesystem grant can accidentally cover more paths than intended. APK represents permissions as explicit capabilities and decides before a fixture adapter executes an operation.

Design

Design

The policy compiler validates agents and capability tokens into typed grant objects. The kernel compares an Operation with those grants, returning a named decision and adding it to an ordered audit trail. Filesystem checks compare normalized directory boundaries. Spend checks use decimal amounts and transaction IDs. A production-deploy capability creates an escalation request; an operator can approve or deny it with evidence, after which a retry observes the stored decision. The CLI can run named synthetic scenarios and render a report.

Engineering decisions

Engineering decisions

Scopes must be absolute canonical paths and cannot include traversal components or grant the root directory. Spend charges use transaction identity so repeating the same charge is idempotent. An escalation can be decided only once. Tests use in-memory adapters for Gmail, files, spend, and deployment, keeping the policy path separate from external side effects.

What the tests verify

What the tests verify

Tests cover policy compilation and named errors, draft allowed versus send denied, directory boundary matching, exact-cap and over-cap spend, deterministic decisions, duplicate charge handling, production escalation, human approvals and denials, and audit order. Simulation and CLI checks also confirm the report includes the synthetic-data notice.
