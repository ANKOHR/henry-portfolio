Overview

Automation with clear boundaries.

OpsPilot combines FastAPI, Next.js, PostgreSQL, Redis, and Dramatiq into a workflow platform. Typed steps, approvals, retries, idempotent ingestion, audit traces, and usage tracking make each run easier to inspect.

  • Typed workflow steps with explicit transitions
  • Human approval gates before selected actions
  • Retries and idempotent ingestion
  • Audit traces and usage tracking
Workflow pipeline
1. Receive

Accept a request and record its source.

2. Plan

Build a typed workflow with explicit steps.

3. Approve

Pause for human review where required.

4. Execute

Run approved actions with retry and audit handling.
