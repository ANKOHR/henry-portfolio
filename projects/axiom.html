Overview

Accounts payable with explicit policy.

Axiom AP Agent handles invoice workflows with deterministic parsing and validation. It makes policy authority explicit, routes uncertain or sensitive actions for human review, records an audit log, and protects against duplicate dispatch.

  • Deterministic parsing and validation
  • Explicit policy authority before actions
  • Human-review paths for exceptions
  • Audit logging with duplicate and idempotency protection
Accounts-payable workflow
1. Ingest

2. Parse

3. Apply policy

Check explicit rules and approval authority.

4. Review or dispatch

Route exceptions or safely dispatch approved work.

Technical details

Validation workflow sketch

def prepare_invoice(invoice, policy):
    parsed = parse_invoice(invoice)
    checks = validate_fields(parsed)
    decision = policy.authorise(parsed, checks)
    if not decision.allowed:
        return request_human_review(parsed, decision)
    return dispatch_once(parsed, decision)
