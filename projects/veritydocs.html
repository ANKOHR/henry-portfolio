Overview

From complex documents to verifiable data.

VerityDocs uses OCR and structured extraction to turn documents into evidence-backed fields. Each field retains provenance, including OCR bounding boxes, while deterministic financial rules check invoice totals.

  • FastAPI and Dockerized Tesseract OCR
  • Field-level provenance and OCR bounding boxes
  • Deterministic financial validation with FIN-001
  • Live demo with 49 backend tests passing

Financial validation rule

subtotal = extracted["subtotal"]
tax = extracted["tax_amount"]
gross = extracted["gross_total"]

matches = subtotal + tax == gross
result = "PASS" if matches else "FIN-001 FAIL"
