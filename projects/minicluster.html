Overview

Explore the behavior behind consensus.

MiniCluster is a compact environment for exercising distributed systems behavior. It focuses on Raft leader elections and how a cluster recovers after network partitions, with a verified suite of 63 passing tests.

  • Raft leader-election behavior
  • Network partition recovery paths
  • Small cluster behavior that is easy to inspect
  • 63 tests passing
Cluster behavior
1. Start nodes

Create a small cluster with independent node state.

2. Elect leader

Run the Raft election and record the leader.

3. Introduce partition

Observe behavior when communication is interrupted.

4. Recover

Restore communication and verify cluster recovery.
