Overview

Make agent regressions visible.

AgentCheck compares agent evaluation runs and makes changes easier to review. Its demo web UI includes result and category filters with latency statistics. In the verified comparison, a baseline scored 18/20 and a candidate scored 16/20, with two planted regressions flagged.

  • Repeatable evaluation and regression workflow
  • Baseline and candidate result comparison
  • Web UI with result and category filters
  • Latency statistics and regression flags
Regression evaluation flow
1. Choose cases

Use a fixed evaluation set for comparison.

2. Run baseline

Record the reference behavior and result.

3. Run candidate

Evaluate the changed agent on the same cases.

4. Review flags

Inspect failures, categories, and latency.
