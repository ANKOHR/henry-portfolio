Overview

Make model changes testable.

EvalGate is an open-source LLM evaluation harness. It brings a deterministic check library and versionable YAML evaluation cases into a repeatable command-line workflow that can run in CI.

The goal is to make expected behaviour explicit so a change can be checked consistently before it is used.

  • Keep evaluation cases in readable YAML files.
  • Use deterministic checks where the expected result can be stated clearly.
  • Run the harness locally and connect checks to CI.
Evaluation pipeline
1. Define cases

Describe inputs and expected behaviour in YAML.

2. Run checks

Use the CLI to apply the declared evaluation checks.

3. Review results

Inspect which cases passed and which need attention.

4. Gate changes

Include evaluation in a CI workflow before release.
